# chat-bot-Furia

## _Chatbot FURIA CS - Experiência Conversacional_

Este projeto é um chatbot simples e funcional para fãs do time de CS:GO da FURIA. Construído como uma landing page HTML, ele oferece uma interface conversacional para responder perguntas frequentes sobre o time, seus jogadores, próximos jogos, resultados e loja oficial.

---

## Features

- Interface de chat moderna e acessível
- Respostas automáticas para perguntas sobre:
  - Próximos jogos da FURIA
  - Resultados recentes
  - Jogadores do time
  - História e fundação
  - Participação em eventos e torneios
  - Loja oficial de merchandise
- Mensagens personalizadas para interação mais natural
- Funciona 100% no frontend, sem necessidade de backend ou APIs externas

---

## Como usar

1. Clone este repositório ou baixe o arquivo `chatbot-furia.html`.
2. Abra o arquivo `chatbot-furia.html` com um navegador moderno (Chrome, Firefox, Edge, Safari).
3. Digite suas perguntas no campo de entrada e envie para interagir com o chatbot.
4. Exemplos de perguntas:
   - "Quando é o próximo jogo?"
   - "Quem são os jogadores da FURIA?"
   - "Qual foi o resultado do último jogo?"
   - "Conte sobre a história da FURIA"
   - "Onde posso comprar produtos oficiais?"

---

- Chatbot baseado em regras simples no frontend
